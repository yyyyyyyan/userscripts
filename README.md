## Get a userscript manager

You need a userscript manager to run these scripts. Install one for your
browser:

- [Violentmonkey](https://violentmonkey.github.io/get-it/) for Chrome,
  Firefox and other browsers.
- [Tampermonkey](https://www.tampermonkey.net/) for Chrome, Firefox and other
  browsers.

If you use Chrome, also turn on user scripts for the manager:

1. Open `chrome://extensions`.
2. Select **Details** on your userscript manager.
3. Turn on **Allow User Scripts**.

Until you do, Chrome stops the manager from running any script.

## Install a script

1. Open the script's install link from the table above.
2. Select **Install this script** on the Greasy Fork page.
3. Confirm in the install tab your userscript manager opens.

Your userscript manager can check for updates and install them for you. Its
settings control how often it checks.

## Supported managers

These scripts are written and tested for Violentmonkey and Tampermonkey, in
Chrome and Firefox. Other managers may work, but they are not supported.

## Privacy

Scripts keep what they store on your device. A script makes no network
requests unless its row in [PRIVACY.md](PRIVACY.md) says so. That row also
says what the script stores and where. Each script's README lists what it can
access on a page.
